# Lessons

Owner: defne. One file per area: `docs/lessons/<area>.md`, with the research-note frontmatter (topic, owner, status, last_verified, review_by, sources, superseded_by).

Entry format: date, what happened, cause, rule, guard status (none | proposed | promoted).

Ladder: lesson -> rule in the owning doc or persona card -> automated guard (hook, lint, test, CI) -> lesson shrinks to a one-line pointer.

Lessons are history, not current state.
