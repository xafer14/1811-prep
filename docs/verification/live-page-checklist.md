# Live-page checklist (backlog B-001)

Owner: ozan (list) and the project owner (browser checks). Purpose: the official pages below blocked automated reading, so their numbers are only search excerpts. A calculator is built only after a page here is checked.

## How to do it (about 30 minutes)
1. Open each link in your own browser.
2. Take a screenshot of the table or text named in "What I need" (or save the page as PDF). If the page has a "last updated" date, include it.
3. Drop the screenshots into the chat. You do not have to type or compare any numbers.
4. The agent reads them, updates the research notes, and marks the item done here.

If a link is dead, search the page title plus the agency name and send what you find.
