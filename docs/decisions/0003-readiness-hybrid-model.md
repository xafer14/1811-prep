# 0003: Hybrid readiness model, current official methods, primary-verified scoring

- Status: accepted (owner chose hybrid 2026-11-24; method and scope defaults accepted 2026-11-24)
- Context: BMI plus self-reported activity cannot validly predict passing a fitness test; several services replaced height/weight tables with waist-to-height ratio; most official standards could only be read as search excerpts. See [fitness-assessment-validity](../research/fitness-assessment-validity.md), [fitness-standards-military](../research/fitness-standards-military.md), [fitness-standards-federal](../research/fitness-standards-federal.md).
- Decision: body composition uses each organization's current official method with an as-of date; events are compared one by one to official minimums; activity level feeds only a labeled time-to-ready range; no overall verdict; calculators only for standards read on an official page, others are link-out until verified.
- Alternatives: pass/fail verdict from BMI and activity (invalid, FTC substantiation risk); readiness band only (less useful); scoring excerpt-level numbers (trust and legal risk).
- Consequences: the tool asks for waist circumference; launch has three calculators; every standard needs a human live-page check before it gets a calculator.
