# Capability proposals

Owner: aras (triage). Any persona may propose; nothing is created or installed without the owner's go.

File name: `NNNN-<kind>-<name>.md`, kind = persona | skill | command | hook | mcp.

Required fields:
- need
- evidence (task refs, lessons)
- overlap check (which existing persona/skill almost covers it, and why that is not enough)
- proposed name, description, tools, model
- cost (tokens, money, maintenance)
- risk
- rollback
- status: proposed | approved | rejected

Triggers: the same need handled ad hoc 3+ times; a persona card mixing concerns or over 120 lines; a repeating lesson; a stack technology with no skill; the owner rejecting the same thing twice.
